# Exchange Rates API (Go)

Rewrite of exchange-rates-api in Go.

## Commands (Docker)
- `make build` — build images
- `make up` — start services
- `make down` — stop services
- `make test` — run tests
- `make migrate` — apply migrations
- `make cron` — run rate update job

Run API: `http://localhost:8080/ping`
